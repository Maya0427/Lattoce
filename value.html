MISSION / VISION / VALUE

私たちは、
何を目指すのか。

MISSION

出会いの交差で、
個人の熱量を解き放つ。

世の中のルールや偏見、固定観念という 「目に見えない縛り」を打ち破る鍵は、 出会いの中にあります。

縦と横の線が交差する 「Lattice（格子）」となり、 一人ひとりが胸に秘めた「やりたい」を 爆発させられる場をつくります。

VISION

誰もが自分の
「やりたい」を
あきらめない社会。

「若者だから」 「この地域だから」 「前例がないから」

そんな言い訳や限界を過去のものにする。 多彩な人とつながり、助け合うことで、 「やりたいことは実現できる」と 誰もが信じられる世界を目指します。

VALUE

3つの
行動指針。

VALUE 01

突破せよ

BREAK THE FRAME

偏見や「普通」という枠組みを、 恐れずに飛び越える。 既存のルールに縛られず、 自分の感情と目標に素直になろう。

VALUE 02

交差せよ

CROSS THE LINES

世代もジャンルもエリアも関係なく、 自分から飛び込む。 異質な価値観や未知の出会いを面白がり、 つながりを自ら創りに行こう。

VALUE 03

証明せよ

PROVE THE IMPACT

つながりを単なる「出会い」で終わらせず、 挑戦に変える。 行動で示し、 出会いがもたらす価値を社会に証明しよう。
